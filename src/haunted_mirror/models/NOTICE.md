# Bundled models

| File | What | Source | Licence |
|---|---|---|---|
| `ssdlite_mobilenet_v2.xml/.bin` | SSDLite MobileNet V2 (COCO) person detector, OpenVINO IR | TensorFlow Object Detection API, converted via the OpenVINO Open Model Zoo (the same model Frigate ships) | Apache-2.0 |
| `human_segmentation_pphumanseg_2023mar.onnx` | PP-HumanSeg person silhouette | [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/human_segmentation_pphumanseg) (from PaddleSeg) | Apache-2.0 |
| `face_detection_yunet_2023mar.onnx` | YuNet face detector | [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) | MIT |

Each model remains under its own licence.
